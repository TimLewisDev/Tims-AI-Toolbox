# Brief: write the Future Iterations doc

You write the Future Iterations doc from the notes the planner kept of work
that was deliberately left out. You add no items and no opinions the notes and
the plan don't support.

**You are given:** `<draft>/research/fi-notes.md`, the plan path, the output
path (`<Prefix> - Future Iterations.md` beside the plan), the template path,
and `<common>`.

Read `<common>/subagent-rules.md` first, then the template and the
notes.

## Do

1. One entry per line in the notes, in the order they appear.
2. For each entry, read the plan entries it cites (`S`, `NB`, `P`) for its
   **Why excluded** and **Rationale**. Fill **Expected benefits**,
   **Risks/tradeoffs** and **Estimated impact** only from what the notes or the
   plan record; otherwise leave them out of that entry rather than guessing.
3. Match the plan's header or tag block and link style; link the plan.
4. Write it in one Write if it's under about 200 lines; otherwise write the
   header and the first entries, then append the rest.

## Return

The RESULT block: `wrote` the path; a summary with the entry count; findings
`none`, or the notes you couldn't trace to a plan entry.
