## P2 — Where does a failed save go?

| | |
|---|---|
| **Status** | Open |
| **Type** | Blocking decision |
| **Decides** | CD1 |

### The question
A save can fail on a full disk. Should the error be shown, or the save
retried until it works?

### Options at a glance
| | A: Show the error (Recommended) | B: Retry quietly | C: Both |
|---|---|---|---|
| **In one line** | A toast says the save failed | Retry every 5 s | Retry, and say so after 3 tries |
| **Main benefit** | Nothing is lost without a word | No interruption | Both |
| **Main risk** | One more message | A silent loss if it never works | More code |

### Recommendation
Option A, because the panel already shows toasts (`src/greet.sh:1`).
